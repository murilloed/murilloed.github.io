Problema e contexto

Caminho mínimo em grade com implementações Python e Rust.

Saneamento · Indústria

Implementação atual

A* e Dijkstra em grade com obstáculos, benchmark determinístico e execução paralela por processos; crate Rust com A* e testes unitários; CLI Rust em protocolo stdin/stdout e adapter Python para comparação.

Próximas etapas

Bindings PyO3; benchmarks maiores e perfil de memória; aceleração não é presumida. ## Rust ```bash cargo test --manifest-path rust/Cargo.toml cargo build --release --manifest-path rust/Cargo.toml python -m spatialsearch.demo --rust-binary rust/target/release/spatial-search ``` No Windows, o binário usa o sufixo `.exe`.

Reproduza o experimento

python -m pip install -e .
python -m spatialsearch.demo
python -m unittest discover -s tests -v
