BiomaData — reconhecimento de imagens ambientais

Resumo do projeto

Objetivo

Apoiar a identificação de mudanças ambientais a partir de imagens de uma mesma área em diferentes datas. O reconhecimento de queimadas e mudanças de uso do solo é a finalidade de evolução do módulo.

Entrega atual

Um módulo de comparação de duas imagens, com percentual de regiões alteradas, diferença média, fonte, datas e localização informadas. O fluxo registra as análises e permite revisão humana dos resultados.

Técnicas e funcionamento

As imagens são reduzidas a uma grade de 32 × 32 valores de luminância. O algoritmo calcula a diferença entre cada posição e usa um limiar configurável para destacar mudanças. A integração geoespacial relaciona a análise ao território informado.

Dados e treinamento

A versão consultada usa comparação matemática de imagens, sem treinamento de rede neural. Um classificador de machine learning exigirá imagens rotuladas, separação entre treino e teste e avaliação por território e período. Não há resultados de treinamento desse classificador confirmados nesta descrição.

Resumo sintético

O BiomaData possui um módulo para comparar imagens ambientais e destacar mudanças entre duas datas. A entrega atual calcula diferenças visuais e registra o contexto da análise para revisão humana. O reconhecimento automático por machine learning é uma evolução que depende de dados rotulados e validação do modelo.

Como interpretar os resultados

Uma diferença visual não comprova uma queimada ou uma ocupação irregular. Nuvens, iluminação e desalinhamento também alteram os pixels. As duas imagens precisam estar alinhadas e o resultado deve ser conferido por uma pessoa qualificada.

Próximas etapas

Consolidar imagens e rótulos autorizados, definir as classes ambientais e treinar e comparar modelos de classificação ou segmentação. Medir erros por classe e generalização em novas áreas antes de apresentar reconhecimento temático como uma funcionalidade validada.

Estudo de caso do módulo de imagens do BiomaData. A descrição distingue a comparação visual implementada da evolução para reconhecimento por machine learning. A ilustração é esquemática e não representa imagens ou resultados reais do projeto.

Reproduza o experimento

O exemplo independente em Python gera duas imagens sintéticas, compara as diferenças e grava um relatório. O módulo institucional e esta demonstração têm escopos distintos.

python -m pip install -e .
python -m biomavision.demo
python -m unittest discover -s tests -v

Resultados e limites

No exemplo sintético, 25% das células ficaram acima do limiar de diferença. Esse número descreve a alteração artificial criada e não é uma métrica de acurácia de reconhecimento ambiental.
