Resumo do projeto

Problema e objetivo

Reconstruir estruturas a partir de fotografias para apoiar inspeções e medições.

Entrega atual

Triangulação de pares estéreo calibrados, exportação PLY e plano de reconstrução COLMAP.

Dados e treinamento

A demonstração usa pontos sintéticos e câmeras conhecidas; não treina redes neurais. Fotografias reais exigem calibração e referências de escala.

Resumo sintético

Transformo observações de duas câmeras em pontos 3D e preparo o fluxo para reconstruir estruturas com fotografias reais.

Resultados e limites

Demonstração sintética reproduzível e relatório JSON. Os fluxos externos estão preparados, mas ainda não foram validados com fotografias reais.

Próximas etapas

Executar com imagens autorizadas, avaliar resultados em dados separados e ampliar a visualização 3D ou análise de imagens.

Reproduza o experimento

python demo.py
python -m unittest discover -s tests -v

Consulte o README para executar os fluxos opcionais com COLMAP, Nerfstudio ou modelos pré-treinados.
