Resumo do projeto

Problema e objetivo

Organizar a reconstrução de áreas com erosão para estudar sua geometria.

Entrega atual

Pipeline COLMAP de extração, correspondência e reconstrução; auditoria de pontos e erro de reprojeção.

Dados e treinamento

SfM ajusta câmeras e pontos, sem treinamento supervisionado. A auditoria demonstrativa usa uma exportação COLMAP sintética; o pipeline em fotos reais ainda precisa ser executado.

Resumo sintético

Preparo o processamento de fotos no COLMAP e verifico a qualidade da nuvem de pontos para apoiar análises de erosão.

Resultados e limites

Demonstração sintética reproduzível e relatório JSON. Os fluxos externos estão preparados, mas ainda não foram validados com fotografias reais.

Próximas etapas

Executar com imagens autorizadas, avaliar resultados em dados separados e ampliar a visualização 3D ou análise de imagens.

Reproduza o experimento

python demo.py
python -m unittest discover -s tests -v

Consulte o README para executar os fluxos opcionais com COLMAP, Nerfstudio ou modelos pré-treinados.
