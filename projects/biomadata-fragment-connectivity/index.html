Resumo do projeto

Objetivo

Explorar a proximidade entre fragmentos de vegetação e suas possíveis ligações.

Entrega atual

Protótipo independente com mapa SVG, dados GeoJSON e relatório JSON para conferência. Inspirado no BiomaData, sem integração automática na aplicação original.

Técnicas e funcionamento

Distância entre bordas, grafo por limiar, componentes conexas e floresta geradora mínima com Kruskal.

Dados e treinamento

Dados sintéticos em coordenadas planas locais em metros. Não há treinamento de IA; o processamento usa geometria e algoritmos explícitos.

Resumo sintético

Criei um modelo que conecta fragmentos próximos e identifica grupos isolados. Ele seleciona ligações curtas para apoiar uma primeira investigação de conectividade ambiental.

Resultados e limites

Com limiar de 18 m, quatro fragmentos sintéticos formaram um grupo conectado. Três ligações somaram 42,52 m de separação entre bordas. Proximidade não comprova um corredor ecológico viável. O modelo ainda não considera espécies, vias, relevo ou resistência da paisagem.

Próximas etapas

Importar camadas autorizadas, validar projeção e qualidade das geometrias e conectar o resultado ao fluxo de revisão do BiomaData. Adicionar raster de resistência e caminhos de menor custo com validação ecológica.

Reproduza o experimento

python -m pip install -r requirements.txt
python demo.py
python -m unittest discover -s tests -v
