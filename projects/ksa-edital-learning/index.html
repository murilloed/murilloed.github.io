Resumo do projeto

Objetivo

Ajudar a organizar editais, identificando conhecimentos, provas, inscrições e cargos para apoiar a gestão por competências.

Entrega atual

Um leitor neural que classifica títulos em seis categorias e guarda os exemplos confirmados ou corrigidos. O repositório público entrega o módulo isolado, testes e uma demonstração reproduzível.

Técnicas e funcionamento

JavaScript e Transformers.js usam o modelo multilingual-e5-small para transformar textos em 384 números. Uma pequena rede neural com 24 unidades intermediárias classifica o título em seis tipos: conhecimentos específicos, gerais, prova, inscrição, cargo ou outros.

Dados e treinamento

Começa com 35 títulos de referência. Após confirmar a leitura ou corrigir um título, o sistema acumula os exemplos e treina novamente o classificador por 180 épocas, com descida de gradiente e entropia cruzada. O modelo de linguagem permanece congelado. Inserir o edital inicia a leitura; aprender depende da revisão humana.

Resumo sintético

Criei um módulo que ajuda a entender a estrutura dos editais. Ele usa um modelo de linguagem pronto para representar os títulos e uma rede pequena para classificá-los. Quando o usuário confirma ou corrige a leitura, esses exemplos entram no treinamento, permitindo adaptar o classificador aos novos editais.

Como interpretar os resultados

Na demonstração sintética, dois exemplos revisados aumentaram a base de 35 para 37. Os pesos mudaram e foram restaurados após reiniciar. A validação teve 3 acertos em 4 títulos antes e depois: uma previsão melhorou e outra piorou. Essa amostra pequena não mede a precisão em editais reais.

Próximas etapas

Ampliar os exemplos revisados e avaliar em editais separados do treino, medindo os erros por categoria. Acompanhar cada atualização para verificar ganhos e regressões antes de ampliar o uso.

Reproduza o experimento

npm install
npm test
npm run demo

A demonstração usa títulos sintéticos e baixa o encoder público na primeira execução. O código não inclui editais pessoais, dados dos usuários ou pesos treinados na aplicação original.
