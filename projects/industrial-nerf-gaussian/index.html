Resumo do projeto

Problema e objetivo

Comparar representações de uma instalação para visitas virtuais.

Entrega atual

Planos de treinamento Nerfacto e Splatfacto; avaliação de imagens por MSE e PSNR.

Dados e treinamento

O código prepara comandos de treinamento por cena. A demonstração calcula métricas em imagens sintéticas; não treina NeRF ou Gaussian Splatting. Treinamento real depende de fotos, poses e ambiente compatível.

Resumo sintético

Preparo uma comparação entre NeRF e Gaussian Splatting para recriar instalações e medir a qualidade das vistas geradas.

Resultados e limites

Demonstração sintética reproduzível e relatório JSON. Os fluxos externos estão preparados, mas ainda não foram validados com fotografias reais.

Próximas etapas

Executar com imagens autorizadas, avaliar resultados em dados separados e ampliar a visualização 3D ou análise de imagens.

Reproduza o experimento

python demo.py
python -m unittest discover -s tests -v

Consulte o README para executar os fluxos opcionais com COLMAP, Nerfstudio ou modelos pré-treinados.
