Resumo do projeto

Problema e objetivo

Separar regiões da cena e comparar sua profundidade relativa.

Entrega atual

Estatísticas por classe, profundidade relativa e adaptador opcional de inferência com modelos pré-treinados.

Dados e treinamento

A demonstração usa mapas sintéticos. O adaptador usa modelos prontos, sem fine-tuning; a execução com imagens reais e avaliação por classe ainda são próximas etapas.

Resumo sintético

Combino máscaras de regiões e mapas de profundidade para resumir a composição de uma cena e apoiar análises visuais.

Resultados e limites

Demonstração sintética reproduzível e relatório JSON. Os fluxos externos estão preparados, mas ainda não foram validados com fotografias reais.

Próximas etapas

Executar com imagens autorizadas, avaliar resultados em dados separados e ampliar a visualização 3D ou análise de imagens.

Reproduza o experimento

python demo.py
python -m unittest discover -s tests -v

Consulte o README para executar os fluxos opcionais com COLMAP, Nerfstudio ou modelos pré-treinados.
